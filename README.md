# eyscher.com

Personal site of Eitan Y. Scher: research, projects and photography ("EYS of the World").

- `index.html`, `photos.html`: the published pages (static HTML, CSS and JavaScript; no framework).
- `img/`: web-sized photographs with location and camera data removed.
- `_source/`: editable sources. After changing them, run `python3 _source/build.py` to regenerate the two pages.
- `CNAME`: points GitHub Pages at eyscher.com.
